      APLICATIVOS

      Servidores

      Até 5 programas rodando junto com os sites — inclusive coisas que não são estáticas.

      APLICATIVOS

      Servidores

      0/5

      Um servidor é um programa seu (Python ou Node.js) que fica rodando e responde no endereço /NOME/, pelo mesmo túnel dos sites. O guardião liga, vigia e reinicia; se uma versão nova não responder, a anterior volta sozinha. Guia completo: docs/SERVIDORES.md.

      Criar servidor
      Caminho dentro do ZIP. Ex.: app.py, server.js, src/index.js
      Deve responder 200. Vazio = só confere se a porta responde.

      CATÁLOGO

      Catálogo dos clientes

      0

      O cliente cadastra os próprios produtos num painel com senha, que abre por cima do próprio site por um botão escondido (5 toques no logo). Os seus HTMLs leem a lista em /_api/NOME/products.json, então você não precisa mexer a cada produto novo.

      Gera uma senha para o cliente. Ela aparece uma vez só.

      Acesso do cliente — guarde agora, a senha não aparece de novo

      SEGURANÇA

      Backups

      Cópias conferidas e criptografadas de cada loja.

      SEGURANÇA

      Central de backups

      Guarda uma cópia conferida e criptografada do site e do catálogo de cada loja (produtos e fotos; a senha do cliente nunca entra). Você pode voltar uma loja a uma cópia anterior sem medo: antes de trocar qualquer coisa o CDBS salva o estado atual e, se algo falhar, recoloca a versão anterior. Uma loja removida também pode ser recuperada, mas volta desativada até você gerar uma nova senha.
